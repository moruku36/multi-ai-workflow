# モデル間コンテキスト引き継ぎテンプレート (Handoff Templates)

各レベル間で成果物や課題を引き継ぐ際に、コピペして使えるプロンプト雛形です。
「前モデルの結論」と「次モデルへの期待」を明確にすることで、手戻りを最小化します。

---

## 1. Level 2 → Level 3 (Gemini実務調査 → ChatGPT思考・設計判断)

Geminiで調査や初期実装を行ったが、「自分のプロジェクト文脈に合っているか？」または「設計として美しいか？」をChatGPTに相談する際のテンプレートです。

```markdown
【前提と相談の目的】
プロジェクトの設計方針について相談したいです。私の過去の経緯や技術方針を踏まえて検討してください。

【Geminiでの調査/作成結果】
--- ここにGeminiの出力・要約を貼る ---

【論点・気になっていること】
1. この設計は、以前話していた〇〇の方針と矛盾しないか？
2. 今後の拡張性を考えたとき、よりシンプルで保守しやすい構成はあるか？
3. あなたの視点で懸念されるリスクや、別の選択肢を提示してください。
```

---

## 2. Level 3 → Level 2 (ChatGPT設計確定 → Gemini+Antigravity実装適用)

ChatGPTで方針・アルゴリズム・設計が固まった後、Antigravity（Gemini）に実務・ファイル変更を実行させるテンプレートです。

```markdown
【タスク: 設計仕様に基づく実装適用】
ChatGPTで以下の設計および実装方針が確定しました。
この内容に沿って、ローカル環境の該当ファイルを実装・修正し、テストを実行してください。

【確定した設計仕様・指示】
--- ここにChatGPTの結論やコードスニペットを貼る ---

【作業スコープ】
- 対象ファイル: `path/to/file`
- 実行すべき検証: テストの実行、リントチェック
- 注意点: 既存のコメントや他の機能への影響がないことを確認すること。
```

## 3. Level 2/3 → Level 4 (成果物 → Claude APIセカンドオピニオン)

GeminiやCodexで作った重要なコードや設計を、Claudeに「批判的レビュアー」として検証してもらう際のテンプレートです。

```markdown
【セカンドオピニオン依頼: 批判的レビュー】
以下の実装・設計について、批判的な視点（Devil's Advocate）からレビューをお願いします。
お世辞や一般的な褒め言葉は不要です。潜んでいる欠陥、エッジケース、セキュリティ上の穴、運用上のリスクのみを箇条書きで指摘してください。

【対象内容】
--- ここにコードや設計書を貼る ---

【特に注視してほしい観点】
- 並行処理やリソースリークの有無
- 異常系・境界値の処理漏れ
- 保守・運用のしやすさ
```
