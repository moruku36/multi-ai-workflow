# タスク別ルーティングガイド (Routing Guide)

日々の業務や開発において、「どのモデルに依頼すべきか」を迷わず即決するための逆引きガイドです。  
エンジニアリング作業だけでなく、一般的なビジネス・リサーチ業務にも対応しています。

---

## 1. 逆引きタスク対応表

| 具体的な作業内容 | 推奨レベル | 理由 |
|---|:---:|---|
| **社外秘データ・顧客アンケート・機密ログの整形** | **Layer 1 (Qwen)** | ローカルPC完結、外部漏洩リスクゼロ、コスト完全無料 |
| **CSVやJSON・議事録の定型フォーマット変換・リスト化** | **Layer 1 (Qwen)** | 高速、定型処理に特化したプロンプト設定 |
| **最新の市場動向・ニュース・競合他社のWebリサーチ** | **Layer 2 (Gemini)** | Google検索連携、最新情報の網羅的な調査性能 |
| **企画書・レポートの下書き作成とファイル自動生成** | **Layer 2 (Gemini)** | AntigravityによるPC上でのファイル作成・編集の自動化 |
| **プロジェクト内の複数ファイルの一括修正・コード実装** | **Layer 2 (Gemini)** | エージェント機能による実務作業代行（テスト実行含む） |
| **日常的なビジネスメール・社内連絡文のドラフト** | **Layer 2 (Gemini)** | スピード重視でサクッと作成 |
| **新規企画のアイデア出し・ビジネス戦略の壁打ち** | **Layer 3 (ChatGPT)** | 過去の文脈・あなたの好みや会社の事情を一番反映できる |
| **複雑なシステム設計・抽象度の高い問題の解き方相談** | **Layer 3 (ChatGPT)** | 深い推論力と論理構築力 |
| **難度の高いアルゴリズム実装や難解バグの究明** | **Layer 3 (Codex)** | Codexの高精度なコーディング推論力 |
| **経営陣提出前・リリース前の重要資料のリスクチェック** | **Layer 4 (Claude)** | 批判的思考（あえて粗探しをする視点）による盲点の洗い出し |
| **他モデルの出力に矛盾や違和感がある時のセカンドオピニオン** | **Layer 4 (Claude)** | 馴れ合いやバイアスを排した客観的な検証 |

## 2. エスカレーション基準（モデルを切り替えるタイミング）

`	ext
Layer 1 (Qwen)
  └─「文脈理解や最新の外部情報が必要」
        ▼
Layer 2 (Gemini + Antigravity)
  └─「設計がしっくりこない」「過去の決定事項と矛盾する」「難問で堂々巡り」
        ▼
Layer 3 (ChatGPT 5.6 Sol / Codex)
  └─「重大な発表・提出」「バイアスを排除して厳しい目で検証したい」
        ▼
Layer 4 (Claude API)
`

## 3. ChatGPT（Codex）利用制限時の立ち回りルール

ChatGPTやCodexの利用制限（Rate Limit）に達した際、**作業全体を止める必要はありません**。

1. **思考・骨子決めは「ChatGPT本体」で行う**
   - 「この企画方針でいく」「この構成案にする」という方針決めは、制限の緩い対話で完結させる。
2. **調査・実務・資料作成は「Gemini + Antigravity（Layer 2）」に渡す**
   - ChatGPTで固めた方針や指示プロンプトをそのままGemini（Antigravity）に貼り付け、実ファイルへの落とし込みを行わせる。
   - （例: *「ChatGPTと以下の骨子を策定した。この方針に従ってプレゼン資料のドラフトをMarkdown形式で作成せよ」*）
