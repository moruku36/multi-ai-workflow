# タスク別ルーティングガイド (Routing Guide)

日々の業務や開発において、「どのモデルに依頼すべきか」を迷わず即決するための逆引きガイドです。

---

## 1. 逆引きタスク対応表

| 具体的な作業内容 | 推奨レベル | 理由 |
|---|:---:|---|
| 大量のログから特定エラーの抽出・整形 | **Level 1 (Qwen)** | ローカルで完結、機密ログの外部流出防止、定型変換に最適 |
| CSVやJSONのフォーマット変換・正規表現置換 | **Level 1 (Qwen)** | 高速、トークン消費ゼロ、単純加工 |
| 最新の公式ドキュメントやGitHubの調査 | **Level 2 (Gemini)** | Web検索・最新情報の走査性能、Antigravityでの並行検索 |
| プロジェクト内の複数ファイルのリファクタ・実装 | **Level 2 (Gemini)** | Antigravityによるツール実行（ファイル読み書き・テスト実行） |
| 日常的なメール・社内チャットの下書き作成 | **Level 2 (Gemini)** | スピード重視、実務定型 |
| 自分のキャリア方針やプロダクトの方向性の相談 | **Level 3 (ChatGPT)** | 過去の文脈・価値観・長期記憶を最も反映できる |
| 複雑なドメインモデル設計・技術選定の壁打ち | **Level 3 (ChatGPT)** | 思考の深さ、多角的な設計議論 |
| 難度の高いアルゴリズム実装や難解バグの究明 | **Level 3 (Codex)** | Codexの高精度な推論力 |
| リリース前セキュリティチェック・盲点洗い出し | **Level 4 (Claude)** | 批判的思考（Devil's Advocate）、バイアスのない検証 |
| 他モデルの出力で矛盾や違和感がある時のセカンドオピニオン | **Level 4 (Claude)** | 異なる視点からの客観的ジャッジ |

---

## 2. エスカレーション基準（モデルを切り替えるタイミング）

```text
Level 1 (Qwen)
  └─「文脈理解が必要」「最新仕様が絡む」
        ▼
Level 2 (Gemini + Antigravity)
  └─「設計が噛み合わない」「個人の過去の決定事項と衝突している」「難問で堂々巡り」
        ▼
Level 3 (ChatGPT 5.6 Sol / Codex)
  └─「重大なリリース」「他モデルのバイアスを排除して客観チェックしたい」
        ▼
Level 4 (Claude API)
```

---

## 3. Codex枠切れ時の立ち回りルール

Codexの利用制限（週次/日次枠）に達した際、**Level 3の思考そのものを止める必要はありません**。

1. **思考・設計は「ChatGPT 5.6 Sol本体」で行う**
   - 「このアーキテクチャでいく」「このインターフェース設計にする」という方針決め・擬似コード作成はChatGPT本体で完結させる。
2. **実装・ファイル適用は「Gemini + Antigravity（Level 2）」に渡す**
   - ChatGPTで固めた設計方針や指示プロンプトをコピーし、Antigravityに渡して実コードへの落とし込みとテストを行わせる。
   - （例: *「ChatGPTで以下の設計が確定した。この仕様に従ってファイルAとBを実装・修正せよ」*）
