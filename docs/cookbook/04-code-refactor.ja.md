# Cookbook 04: コードのリファクタリング

[English](04-code-refactor.md) | [日本語](04-code-refactor.ja.md)

リファクタリングは動作を保ちながら構造を改善します。先に目的、範囲、受け入れ条件を定め、現状の挙動を確認できる根拠と既存テストを把握します。

## 進め方

1. Product OwnerとDottieが範囲と受け入れ条件を明確にする。
2. 既存実装、関連文書、作業ツリーの変更を確認する。
3. 小さな変更を行い、必要なテストを実行する。
4. 別担当によるレビューが必要なら、実装とレビューを分ける。
5. 変更点、テスト結果、未確認事項を報告する。

コード変更時は影響するREADME、使い方、設計文書と既存の日英対応ページを更新します。ローカルテストはlive稼働やdeployを証明しません。ユーザー承認、実行環境の権限、テスト成功、稼働環境反映を別の段階として記録します。
